# Instructions for AI coding agents

This repository is a library of Kaspa builder notes written for you.

1. Read `00-agent-rules.md` first and follow it. Its "How strict to be" section decides how much of the rest applies to the project in front of you.
2. Read `README.md` for the index and the "Which files for what" list, then read only the files that match the task.
3. Before writing code that talks to a node, builds, signs or broadcasts, read `14-sdk-cookbook.md`.
4. When a node, SDK or wallet refuses something, look the message up in `13-node-error-messages.md` before changing anything.

If your tool can open only one file, `llms-full.txt` holds every file in reading order.
